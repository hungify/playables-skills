# playables-skills

Agent skills for YouTube Playables games (Phaser 2D / Three.js 3D, TypeScript, bun).

Some skills are adapted from [opusgamelabs/game-creator](https://github.com/opusgamelabs/game-creator)
(`game-architecture`, `game-assets`, `game-audio`, `game-designer`, `game-qa`, `improve-game`,
`review-game`); the rest (portal SDK guides, `multi-portal-compliance`) are original.

```bash
npx skills add hungify/playables-skills --agent claude-code   # install
npx skills check                                              # is anything outdated?
npx skills update                                             # update to latest
```
